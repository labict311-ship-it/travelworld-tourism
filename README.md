# TravelWorld 🌍

A colorful, responsive tourism discovery website featuring destinations in Bangladesh and around the world.

## Features

- Responsive layout for desktop, tablet and mobile
- Destination search and region filters
- Sort destinations alphabetically
- Destination detail pop-up
- Save / remove favorite destinations (stored in browser localStorage)
- Trip enquiry planner that prepares an email draft
- Mobile navigation and accessible interactive controls

## Destinations

**Bangladesh:** Cox's Bazar, Sajek Valley, Sylhet, Sundarbans

**Worldwide:** Dubai, Maldives, Paris, Swiss Alps, Bali

## Tech stack

- HTML5
- CSS3
- Vanilla JavaScript
- Bootstrap Icons
- Google Fonts
- GitHub Pages

## Run locally

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in a browser, or use the Live Server extension.

No build step or package installation is required.

## Publish with GitHub Pages

1. Open the repository **Settings**.
2. Select **Pages** from the sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/(root)**, then click **Save**.
5. Wait for GitHub Pages to publish the site. The URL will appear in the Pages settings.

## Notes

Destination photos are loaded from Unsplash over the internet. The trip planner currently creates an email draft; it does not store bookings or send emails automatically. This is a front-end demo and does not include a booking backend.
